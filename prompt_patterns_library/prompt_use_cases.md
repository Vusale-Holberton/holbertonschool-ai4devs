# Prompt Use Cases

## Code Quality
- **Refactoring**
    - **Goal**: Improve readability and performance
    - **Input**: Source function in [LANGUAGE]
    - **Output**: Optimized code + explanation
- **Style Enforcement**
    - **Goal**: Enforce consistent naming and formatting
    - **Input**: Code block
    - **Output**: Rewritten code with consistent style

## Debugging
- **Error Identification**
    - **Goal**: Find root cause of logic errors
    - **Input**: Broken code + error logs
    - **Output**: Fix suggestion
- **Edge Case Analysis**
    - **Goal**: Identify potential failure points
    - **Input**: Function logic
    - **Output**: List of edge cases

## Documentation
- **API Documentation**
    - **Goal**: Generate professional comments
    - **Input**: Source code
    - **Output**: Markdown documentation
- **README Generation**
    - **Goal**: Create project overview
    - **Input**: Project details
    - **Output**: Structured README.md

## Testing
- **Unit Test Generation**
    - **Goal**: Create automated tests
    - **Input**: Function code
    - **Output**: Test suite (PyTest/Jest)
- **Mock Data Generation**
    - **Goal**: Create realistic sample data
    - **Input**: Schema structure
    - **Output**: JSON/SQL mock data
