# Data Model

### 1. User Entity
Represents a team member participating in the hackathon.
- **Attributes:** `id` (UUID), `username` (String), `role` (Enum: Developer, Manager, QA), `skills` (List), `availability_status` (Boolean).

### 2. Task Entity
Represents a specific work item within the hackathon.
- **Attributes:** `id` (UUID), `title` (String), `description` (Text), `priority_score` (Float - AI generated), `assigned_user_id` (Foreign Key), `status` (Enum: Todo, InProgress, Done).

### 3. AI_Insight Entity
Represents the feedback or analysis generated by the AI system.
- **Attributes:** `id` (UUID), `related_task_id` (Foreign Key), `insight_type` (String: Suggestion, Warning, Summary), `content` (Text), `timestamp` (DateTime).

---

**Relationships:**
- A **User** can be assigned to multiple **Tasks** (One-to-Many).
- A **Task** can have multiple **AI_Insights** generated for it (One-to-Many).
