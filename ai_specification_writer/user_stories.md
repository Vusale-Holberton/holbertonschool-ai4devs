# User Stories for CarpoolConnect

## User Story 1
As a Employee (Driver/Passenger), I want to log in using my corporate email so that I can access the trusted platform and ensure all participants are my colleagues.
- **Acceptance Criteria 1**: System validates the email domain against the approved corporate list.
- **Acceptance Criteria 2**: User receives a verification link or uses SSO provider.
**Priority**: MVP

## User Story 2
As a Driver, I want to post my commuting route and schedule so that potential passengers can see when and where I am driving.
- **Acceptance Criteria 1**: Driver can set pickup point, destination, and departure time.
- **Acceptance Criteria 2**: Driver can specify the number of available seats clearly.
**Priority**: MVP

## User Story 3
As a Passenger, I want to search for rides by destination and time so that I can find a colleague who is heading to the same office.
- **Acceptance Criteria 1**: Search results show matches within a 5km radius of the requested route.
- **Acceptance Criteria 2**: Results are sorted by departure time.
**Priority**: MVP

## User Story 4
As a Passenger, I want to book a seat in a colleague's car so that I can secure my commute for the next day.
- **Acceptance Criteria 1**: Driver receives a notification to accept or decline the request.
- **Acceptance Criteria 2**: Booking status is updated to "Confirmed" once accepted.
**Priority**: MVP

## User Story 5
As a Driver, I want to see the total CO2 emissions I have saved by carpooling so that I can feel proud of my environmental impact.
- **Acceptance Criteria 1**: Dashboard calculates savings based on trip distance and number of passengers.
- **Acceptance Criteria 2**: Data is visualized in a monthly chart.
**Priority**: High

## User Story 6
As an Employee, I want to rate my carpooling partner after the trip so that other colleagues can know who is reliable and safe.
- **Acceptance Criteria 1**: Users can leave a 1-5 star rating.
- **Acceptance Criteria 2**: Feedback is only visible to verified employees.
**Priority**: Medium

## User Story 7
As a Corporate Admin, I want to download a report of total company carbon savings so that I can include it in our sustainability goals report.
- **Acceptance Criteria 1**: Admin can filter data by department or date range.
- **Acceptance Criteria 2**: Report is exportable in PDF or CSV format.
**Priority**: Medium

## User Story 8
As an Employee, I want to set an emergency contact in my profile so that someone can be notified in case of an incident during the commute.
- **Acceptance Criteria 1**: System allows adding a phone number and name for emergencies.
- **Acceptance Criteria 2**: A "Share Trip Status" button is available during the active ride.
**Priority**: High
