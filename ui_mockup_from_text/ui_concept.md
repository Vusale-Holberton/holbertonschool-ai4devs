# UI Concept - Task Manager App

## Purpose
The purpose of this application is to provide a comprehensive project management dashboard that simplifies task tracking, team collaboration, and workflow visualization for better productivity.

## Users
- **Project Managers**: Users who need to oversee multiple projects, track team progress, and manage deadlines.
- **Team Members**: Individuals who need to view their assigned tasks, update status, and collaborate on shared files.

## Core Screens
- **Dashboard**: A central hub showing project cards, active tasks, and a real-time productivity activity graph.
- **Task Creation Screen**: A dedicated form to add new tasks with priority levels (To-do, Work, High Priority).
- **Activity & History**: A view for tracking completed tasks, user activity trends, and historical project data.

## Actions
- **Create New Task**: Users can click the "New Task" button to add a task with title, priority, and deadline.
- **Update Task Status**: Drag and drop or select status updates for current project tasks.
- **Track Productivity**: View daily notes and visual graphs to monitor work trends over time.
